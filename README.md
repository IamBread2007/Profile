# IamBread — Personal Profile Site

Personal developer website for **IamBread** ([iambread.id.vn](https://iambread.id.vn)).

## ✨ Features

- **Retro Terminal Boot Animation**: Authentic interactive terminal startup sequence with realistic command typing, apt package installation, and deployment progress bar (powered by TypeIt).
- **In-Place Hash Views**: Fast client-side section switching between `/home`, `/about`, `/projects`, and `/blog` with zero layout jarring.
- **5 Selectable Desktop Companions**: Live wandering Oneko companions (Classic, Dog, Maia, Tora, Vaporwave) switchable via top-left dropdown with URL synchronization.
- **Catppuccin Macchiato Theme**: Deep, refined aesthetic palette built with Tailwind CSS & DaisyUI.
- **Floating Music Player & Retro Badges**: Retro 88x31 web badges, supporter banner, and audio widget.

## 🛠️ Tech Stack

- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
- **UI & Styling:** [Tailwind CSS 4](https://tailwindcss.com/) & [DaisyUI 5](https://daisyui.com/)
- **Animation:** [TypeIt](https://typeitjs.com/)
- **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
- **Presence & Discord:** [Lanyard](https://github.com/Phineas/lanyard)
- **Deployment:** [Vercel](https://vercel.com/) / Custom Domain [iambread.id.vn](https://iambread.id.vn)

## 🚀 Development

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build production static export
npm run build
```
